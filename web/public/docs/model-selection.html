The picker reads OpenRouter’s current catalog when you ask. It only lists zero-priced text models with a documented output allowance large enough for a review. It does not change the selected model until you choose one, and it never switches to a paid model automatically. A listing is not a benchmark result or a promise of capacity.

As checked on 20 October 2026, OpenRouter documents 20 free-model requests per minute and 50 per day below its purchased-credit threshold, or 1,000 per day after at least 10 credits purchased. These are provider account limits, not a shared allowance supplied by Bounty Operator.

Free does not mean confidential. Check OpenRouter provider logging and the actual model host’s terms before sending a private report. OpenCode’s free models and privacy exceptions vary by model; some collect data to improve the model, and NVIDIA trial endpoints prohibit confidential or personal data. Start with public or invented examples unless the program permits the selected data handling.

These are independent services, not claimed partnerships. Bounty Operator’s own hosted Model API remains a separate prepaid product.

Compare cost and readiness

Check the model’s current availability before starting. In the catalog, switch workload view to compare estimated token costs, including the minimum request charge. An agent can make several requests for one task, so set an output limit and a spending cap on its API key.

Estimates are not quotes for a completed investigation. Credit is reserved before a request, and the unused portion is released after settlement. A self-hosted model may take several minutes to start after idle. Allow for that startup time when choosing a model for interactive work. See charging and timeout details.

Choose where your content goes

Read the hosting provider and source details on the model card. Our self-hosted RunPod deployments disable prompt and response logging and cross-request prefix caching. Managed models use Infron or OrcaRouter, including any downstream providers, under their own terms and retention policies. They do not come with a zero-retention guarantee.

Send only material you are authorized to share with the selected providers. Review the data handling details before connecting confidential work.

Read the evidence in context

Our Paydirt benchmark, published 3 October 2026, measures small-file Solidity and TypeScript review and checking draft reports. Compare its errors, costs and evaluation method alongside its scores. It does not measure whole-repository audits or live web and cloud assessments.

Wiz Cyber Model Arena is an external reference for broader tasks. Its results evaluate a model together with its agent harness. They do not score our hosted variants: a base model’s result does not transfer to a fine-tune, quantized version or different harness. If the exact setup has no matching evaluation, its performance is unmeasured here.

Start with a small authorized task whose outcome you can check. Keep the model, harness and settings recorded so comparisons mean something.
