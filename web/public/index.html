Every review ends in one of five verdicts.

One decision, with the file and line behind it. The draft stays yours to rewrite.

  • Submit

    Every decisive claim is backed by the supplied code and proof. File it.

  • Rewrite, then submit

    The finding holds. The draft misstates its severity, impact, preconditions or fix.

  • Prove first

    The claimed impact is not demonstrated on the real path yet. One artefact is missing.

  • Hold: duplicate

    A known issue, an audit note, a branch or your own earlier report has the same root cause or the same fix.

  • Drop

    The code contradicts the root cause, the behaviour is the design, or the rules exclude it.

      Questions
      
    
      I already pay for my model. Why pay for this?
      Your provider charges for the model. The US$10 pays for Bounty Operator: no daily limit, the Gauntlet, Panel review and 4 reviews running at once. Model usage is not included. Pricing
      Can I use my ChatGPT or Claude subscription?
      Yes, for 3 review types: code security, Solidity and draft reports. Copy the prompt into your chat and paste the answer back here. The other review types need an API key. Model options
      Where do my files go?
      Your files and API key pass through our server to your provider. The server adds the review instructions and stores no files, prompts, keys or results. A copy-paste prompt stays in your browser until you copy it. Privacy details
      Which models can I use?
      Choose a model from OpenRouter, Anthropic, OpenAI, Google Gemini, xAI, DeepSeek, Mistral or Groq, on your own API key.
      How do I cancel or get help?
      Cancel in the Stripe billing portal. Access continues until the end of your paid week. Contact support@bountyoperator.com for access problems or billing help. Refund terms
