      Questions
      
    
      Can I use my ChatGPT or Claude subscription?
      Yes. Code review, Solidity review and report review can be copied into your chat app. Paste the answer back to view it here. Other review types need an API key. Model options
      Where do my files go?
      Your files and API key pass through our server to your provider. The server adds the review instructions and stores no files, prompts, keys or results. Prompt export stays in your browser until you copy it elsewhere. Privacy details
      Which models can I use?
      Choose a model from OpenRouter, Anthropic, OpenAI, Google Gemini, xAI, DeepSeek, Mistral or Groq. The three core reviews also work through prompt export with your chat or local model.
      How do I cancel or get help?
      Cancel in the Stripe billing portal. Access continues until the end of your paid week. Contact support@bountyoperator.com for access problems or billing help. Refund terms
