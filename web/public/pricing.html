Pricing questions

What counts as a hosted review?

One review profile run through bountyoperator.com on your own API key, from the workbench or from a coding agent with run_review. Exporting the prompt of a core profile to your chat app does not count and has no daily limit. Neither does a core profile prepared over MCP for your agent’s own model.

Which profiles does the free review cover?

Any single profile, all eleven. Code security review, Solidity review and Challenge a draft report are the three core profiles: they also export as a prompt and prepare over MCP. The other eight run hosted only, in the workbench or through run_review: scope and impact fit, design intent and actors, prior-art overlap, proof review, severity calibration, triager simulation, report editor and scanner triage.

When does the free review reset?

At 00:00 UTC. A review the provider fails, refuses or cuts off at the start does not use the day’s allowance.

What does Operator add?

Unlimited hosted reviews, the Gauntlet, Panel review and four hosted reviews running at once. The gauntlet from a coding agent over MCP uses seven hosted reviews, so it runs on Operator too.

Who pays for the model?

Your provider bills model usage to your own key. The US$10 per week covers the hosted workbench and does not include model usage.

How does billing work?

US$10 billed weekly, renews until you cancel in the Stripe portal; access runs to the end of the paid week.

Can I use a chat subscription instead of an API key?

Yes, on both plans, for the three core profiles: code security review, Solidity review and challenge a draft report. Export the prompt, paste it into your chat app and paste the answer back. The other profiles run hosted on an API key.

Do I need an email address or a card for the free plan?

No. An account is a passkey. A card is entered only at Stripe when you buy Operator.
